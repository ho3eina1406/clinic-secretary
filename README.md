# منشی مطب — نسخه آزمایشی (MVP)

یک نمونه اولیه با FastAPI و SQLite برای مدیریت ساعت‌های آزاد و رزرو آزمایشی.

## اجرا

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export ADMIN_KEY='یک-رمز-طولانی-و-تصادفی'
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

سپس `http://localhost:8000` را باز کنید. در ویندوز PowerShell:
`$env:ADMIN_KEY='یک-رمز-طولانی-و-تصادفی'`

## امکانات فعلی
- تعریف ساعت‌های آزاد با تاریخ میلادی و قالب `YYYY-MM-DD HH:MM`
- تنظیم نام مطب و مبلغ پایه
- ثبت چند کارت بانکی در پنل
- ثبت رزرو آزمایشی با مبلغ یکتای مبلغ پایه + عدد تصادفی ۱ تا ۹۹۹ تومان
- انقضای رزرو در انتظار پس از ۱۵ دقیقه
- تأیید دستی رزرو توسط منشی با کلید مدیر

## محدودیت‌ها و هشدارها
- این نسخه هنوز به پیام‌رسان بله، پیامک بانکی، تقویم شمسی یا درگاه/تطبیق واقعی بانکی وصل نیست.
- مبلغ تصادفی فقط شناسه کمکی است و **اثبات پرداخت نیست**؛ پرداخت را صرفاً با مبلغ تطبیق ندهید.
- پنل فعلی برای استفاده عملیاتی امن نیست؛ احراز هویت کامل، HTTPS، محافظت CSRF، محدودسازی درخواست و ثبت رویدادها لازم است.
- مخزن عمومی است؛ اطلاعات واقعی بیمار، شماره کارت واقعی، توکن ربات و رمزها را در این مخزن قرار ندهید.
- پیش از انتشار روی اینترنت، حتماً `ADMIN_KEY` قوی را در متغیر محیطی سرور تنظیم کنید. مقدار پیش‌فرض فقط برای توسعه محلی است.
